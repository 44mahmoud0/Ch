Simulation to Production: Native .NET 10 Architecture

Mahmoud AI replaces legacy simulation layers with a high-performance native Windows 10/11 desktop architecture built on .NET 10 LTS and WinUI 3.
The core runtime orchestration combines a production-grade TaskGraph V2 scheduler with an asynchronous event hub for low-latency mission execution.
Durable SQLite mission-event persistence ensures idempotent hashing and comprehensive state recovery across application restarts.
Security boundaries are strictly enforced by revocation-aware capability leases and the CapabilityGuardedAutomationBackend to prevent unauthorized side effects.
