Hardened Security: CsWin32 and Immutable Leases

Replaced hand-maintained Win32 interop declarations with pinned Microsoft.Windows.CsWin32 source-generated interop, ensuring type safety and narrow API surface.
Eliminated cancellation race conditions by storing immutable cancellation token snapshots per lease handle, guaranteeing atomic revocation during side effects.
Strengthened window targeting with strict HWND validation, process identity checks, and mandatory pre-action revalidation to prevent target mismatch.
Retired legacy synchronous permission requests to prevent UI thread deadlocks, transitioning all capability approvals to a non-blocking asynchronous flow.
